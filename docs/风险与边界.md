# 风险与边界（诚实说明）

> 参赛作品《KB-Embodied-Agent · 企业知识库具身客服》。本文件说明**我们明确知道的能力边界**，
> 供评委复现时对照；也是我们自己在开发中防止\"讲到哪算哪\"的清单。

## 1. 平台侧的硬约束（决定了架构）

| 事实 | 后果 | 我们的处置 |
|---|---|---|
| 魔珐星云 SDK 文档中 **Function Calling / 工具调用 / MCP 零命中** | 行动层无法由 SDK 提供 | **行动层自研**：SDK 侧关闭 `auto_send_asr_to_llm`，由我方 Agent 层接管\"听→想→做→说\"，在回答前后插入 RAG 检索与工具调用 |
| SDK 并发上限 3 路（开发调试级） | 不适合做真并发压测 | 演示环境单会话串行；不承诺高并发 |
| 基础音色 0.5 积分/分钟、无人互动不计费 | 录制演示片成本≈0 | 演示片用真实链路录制，不做\"只截图\"的伪演示 |
| 星云 SDK 非商用免费、商用需书面授权 | 赛后并入商用产品需谈授权 | 本仓库不含任何魔珐代码；`SDK 接入`为前端运行时加载，仓库只留接入点 |

## 2. 离线演示模式（`DEMO_MODE=offline`）边界

- **是什么**：不经星云实时驱动、不消耗积分，用同一套后端链路（会话签发 → RAG → 工具调用 → Widget 渲染）演示完整交互。
- **不是什么**：**不是**"假装有数字人"。离线模式下前端用 CSS 状态动效替代 3D 形象，并在界面上**明确标注**"离线演示"。
- **为什么要有**：① 评委无需积分与网络即可复现；② 平台积分/凭证赛后失效也不至于\"代码跑不起来\"；③ 离线/降级本身是工程可靠性的一部分。
- **当前限度**：离线问答是**预置脚本**（覆盖问候/营业时间/退换货/补贴/报价/转人工/国标 7 类示例），
  **不具备通用理解能力**；自由问答必须走在线模式（大模型）。

## 3. 数据与隐私

- 仓库内 `kb/` **只有虚构示例语料**；真实企业语料仅存在于客户本地环境，**永不入库、不入仓库、不上传第三方**。
- 前端**不内置任何硬编码密钥**：`appSecret` 只从服务端 `.env` 读取，由 `/api/session` 在建会话时下发（TTL 默认 900s）。
- `.env` 已在 `.gitignore`；仓库只提供 `.env.example`；CI 自带密钥扫描，命中即拒绝合入。

### 密钥边界（不夸大）

星云 SDK 的 `appSecret` 属**浏览器侧签名凭证**——厂商文档明确说明它需要下发给前端才能建立实时会话，
因此本项目**不宣称"前端零密钥"**，只承诺：仓库无密钥、密钥只在服务端、会话短时、加载失败即回退离线。
生产环境的更高安全等级做法是向星云后端换取**一次性 token**再下发；本项目已预留该位置、尚未实现。

## 4. 明确不做的事

| 不做 | 原因 |
|---|---|
| 竞价广告 / 刷量 / 伪造引用 | 与产品定位（可验证）冲突 |
| 声称自研 3D 引擎或语音合成 | 表达层用星云 SDK，如实标注依赖 |
| 把\"通用大模型随手就能做\"的能力包装成独创 | 我们的差异化在**企业私有语料 + 工具调用闭环 + 可现场演示的端到端** |
| 承诺\"一定被大模型引用\" | GEO 服务同口径：只承诺过程可验证，不承诺结果 |

## 5. 已知未完成项（不藏）

- `web/` 前端已补写并跑通**离线全链路**；**在线分支（星云实时驱动）代码已就位，尚未在真实凭证下联调** —— 需要控制台的 `App ID / App Secret`。此时前端会自动回退离线表现，不影响离线演示。
- 行动层当前为**进程内工具桩**（`call_tool`），MCP 传输（`MCP_SERVER_URL`）已预留、尚未接入真实 MCP Server。
- 演示视频尚未录制（分镜见 `docs/参赛材料清单与时间表.md`）。
- Docker 一键部署：`backend/Dockerfile` 已补齐，但**开发机 Docker Desktop 未启动，容器构建尚未实跑验证**。

## 3.5 体检判定口径（不构成合规结论）

`/api/selfcheck` 的达标判定（「应」全满足=达标；「应」未满足 ≤3 且不涉一票项=基本达标；否则不达标）
是**本项目依据标准条文自订的工程化口径**，用于内部自查与整改排序；标准原文并未规定此类判定规则。
逐项数据取自 `kb/standards/gbt47746-checklist.json`（可整体替换为企业自有条款库）。
