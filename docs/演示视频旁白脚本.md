## 回答策略口径（与成片旁白一致）

平台只负责表达，**转不转人工由我们自研的行动层决定**，三层路由：

1. **知识库命中** → 依据语料据实作答，附出处；
2. **未命中** → **智能引导**：跟业务无关的问题得体回应并把话题拉回业务；需求模糊则反问澄清（同一会话引导上限 2 次）——**不滥用转人工**；
3. **只在这 4 类转人工**：客户明确要求人工、投诉、高风险（证件/金融/急症）、连续引导 2 轮仍未定位需求。

资料不足时大模型只回 `NO_INFO`，绝不编造；任何路径都不返回空回答（一声不吭比转人工更糟）。

## 时长/电平验收口径

- 每段配音时长必须落在自己的窗口内（配音超窗＝会被后一段压掉）。实测 **12 段全部 OK**。
- 逐段电平实测：人声段均值约 **-19 dB**、峰值 **≤ -1.2 dB**（不削波）；空档为 **-91 dB**（真静音）。
- 合成注意：人声轨必须用 `apad` 补齐到画面等长，**不要用 `-shortest`**，否则片尾会被截。
- 末段收尾前留 ~1s 静默再上结尾卡，避免旁白被卡点切断。

## 复现命令

```bash
python _tts.py          # 生成 12 段配音并核对时长窗口
bash _assemble6.sh      # 三段拼接（主线 + 智能引导 + 红队台，299s）
bash _mix_audio.sh      # 按时间轴铺轨 + 响度归一 + 与画面合成
bash _mix_av3.sh        # 混入数字人原声（含引导补拍段）
```

补拍段（`?auto=9`）为页面内置演示脚本，可在 `web/index.html` 中复现。
