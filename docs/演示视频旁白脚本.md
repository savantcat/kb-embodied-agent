# 演示视频旁白脚本（最终版 · 与成片时间轴对齐）

成片：`kb-embodied-agent_演示视频_参赛版_带解说.mp4`，总长 **274.8 秒（4 分 35 秒）**，1920×1080。
配音：edge-tts `zh-CN-YunyangNeural`，语速 +10%，响度归一到 `I=-16 / TP=-1.5`。

时间轴结构：**0–180s 主镜头（段1–6）**，**180–275s 红队台（段7）**。

| 起点 | 段 | 旁白 |
|---|---|---|
| 1s | 01 开场 | 这是企业知识库具身客服。屏幕上这位，是一个三维数字员工。它背后不是通用聊天机器人，而是这家企业自己的知识库。 |
| 25s | 02 答疑 | 先看它怎么回答专业问题。国标要自查多少项——答案来自我们自建的企业语料，不是模型的记忆：六十一项，四十八项应、四项宜、九项可，其中五项是一票项。答案下方，标着出处。 |
| 52s | 03 行动层卡片 | 关键差别在能干活。它不只说，还调工具：合规自查清单直接生成卡片，客户可以照着逐条整改。行动层是我们自研的，平台只负责表达。 |
| 77s | 04 合规体检 | 再看合规体检。它拿国标六十一项逐条对表，标出待整改项，其中有一票项——任何一项不满足，整体就不达标。整改清单一键导出，能直接当团队待办。 |
| 101s | 05 真转人工 | 问不到依据时，它不编。语料里没有的内容，它会明确说不知道，并主动转人工，把身份信息、历史对话和问题描述一起交接过去，客户不用再重复描述一遍。 |
| 127s | 06 坐席接管 | 人工坐席在坐席台看到工单，接入会话，数字人立即暂停应答。处理完，一键转回数字客服，数字员工会主动开口，确认问题是否已经解决。 |
| 153s | 07 记忆·适老·弱网 | 它记得住客户，不用重复自报家门。一键适老化，字号和对比度立刻放大；弱网演练里，断网自动降级成文字加卡片，网络恢复再重连数字人。每次问答都留痕，一键停可以让 AI 立即停止作答。 |
| 185s | 08 红队台介绍 | 这是本作品最原创的一环：双数字人红队测试台。左边是我们的 AI 客服，右边是扮演刁难客户的红队数字人。 |

| 259.5s | 11 收尾 | 一票项五条全部达标。企业知识库具身客服，答得有依据、干得了活、转得了人工。 |

## 时长/电平验收口径

- 每段配音时长必须落在自己的窗口内（配音超窗＝会被后一段压掉）。实测 11 段全部 OK。
- 逐段电平实测：人声段均值约 **-19 dB**、峰值 **≤ -1.4 dB**（不削波）；空档为 **-91 dB**（真静音）。
- 合成注意：人声轨必须用 `apad` 补齐到画面等长，**不要用 `-shortest`**，否则片尾会被截。

## 复现命令

```bash
python _tts.py          # 生成 11 段配音并核对时长窗口
bash _mix_audio.sh      # 按时间轴铺轨 + 响度归一 + 与画面合成
```
