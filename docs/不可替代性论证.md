# 不可替代性论证：「为什么非数字人不可」（评审权重 35%，核心加分项）

> 关键：绝大多数参赛作品会写成"数字人比文本框更亲切"——那是**感受性**论证，评委不买账。
> 本文件给的是**约束性**论证：在什么具体条件下，纯文本 / 纯语音**做不到**。

## 一、场景选型：企业知识库具身客服（知识服务型 + 效率助手型）

主角设定：**中小微企业**（服务型门店、园区/政务咨询点、医疗器械与技术服务商）的对外知识前台。

知识资产（真实、可替换）：产品与服务口径、售后与退换规则、政策与补贴申报流程、
**AI 客服国标合规口径（GB/T 47746—2026，61 项自查）**、知识库建设与交付方法论。
服务对象：到店/来访顾客、**中老年与低识字客群**、需要办事而不是聊天的客户。

本作品把企业自己的知识库**化身成一位能开口、能指、能办事的具身客服**：
它说得出依据、指得清条目、被打断也能接住，还能当场把清单和报价递到客户手上。

## 二、三类"纯文本做不到"的硬约束

| # | 约束 | 纯文本 / 纯语音为什么失效 | 具身交互为什么必需 |
|---|---|---|---|
| C1 | **输入约束**：到店顾客不打字，中老年客群键盘输入成本极高 | 文本框把交互成本转嫁给用户；纯语音答复又要用户在长内容里自己找条目 | 开口即问；数字人**边说边指**，答案直接以卡片呈现在客户眼前 |
| C2 | **认知约束**：多步知识（合规整改、申报流程、售后条件）读文字会漏步、会读错 | 长文本播报是单向灌输，无法确认听懂，无法按追问重组 | 逐条讲、**可被打断**（`interrupt()`）、可对某一条深入；表情与手势承载"重点在哪" |
| C3 | **信任约束**：涉及钱与合规（补贴、报价、售后责任），用户对"一个对话框"天然不信 | 文本框无法传递"我在认真听"与"我确认过依据" | 有形象、有表情、有手势的应答显著提升信任；**同时**把依据原文与来源作为可展开内容同步呈现——可信但不失温度 |

**补充（本作品特有）**：我们把"信任"做成了**可验证的机制**，而不是仅靠观感——
一键停（出事立即停用 AI、全部转人工）、操作留痕（每次问答落盘可回查）、
可审计引用（每条回答可展开依据原文）。这三点让"信任"从主观感受变成可审计事实。

## 三、行动层：从"回答问题"升级为"当场办事"

纯对话方案只能给一段文字，客户还要自己填表、自己算、自己对照标准。

本作品在对话中直接**调用工具（Function Calling / MCP）**并**以多模态 Widget 当场呈现结果**：

| 工具 | 交付物 | 对应标准动作 |
|---|---|---|
| `policy.selfcheck` 国标体检 | 达标判定 + **待整改清单**（61 项，★标注一票项），可导出 Markdown | 逐项对表、给出整改动作 |
| `kb.audit` 知识库体检 | 覆盖率 + **语料缺口清单**（未覆盖问题即补料待办） | 让知识库可以被"体检"而非上线即腐烂 |
| `handoff.human` 转人工 | 交接卡（原因 + 目标队列 + 上下文） | 命中一票项/未命中时主动转人工，不编造 |
| `quote.calc` 报价 | 结构化报价卡 | 现场"办事"而非让客户自己算 |

这正是命题"行动层 = 可执行任务的 Agent 载体"的完整落地，也是**纯文本框结构上做不到**的部分。

## 四、反向论证：为什么不是"手机 App / 小程序客服"

- 到店与来访场景用户**停留时间短**，不愿装 App、不愿扫码填表；
- 屏幕本身是公共且闲置的（大屏 / 商显 / 自助终端），**数字人是"零门槛公共前台"**；
- 与硬件天然匹配：命题方 SDK 支持 Web 与 Android 多端，**同一份业务内核可迁移到多种终端**；
- 对小微企业而言，**不需要他们改业务流程**——把已有知识库接上就能上线，这是落地成本的关键。

## 五、与纯语音方案的对比（第二层不可替代性）

| 维度 | 纯语音助手 | 本作品 |
|---|---|---|
| 涉及多条并列内容（61 项清单、整改动作） | 只能念，用户记不住、无法回看 | **边念边出卡片**，条目可留存、可导出 |
| 依据溯源 | 无法展示 | 每条回答可展开**依据原文与来源** |
| 打断与追问 | 往往整段重播 | `interrupt()` 立即停止并回到聆听姿态 |
| 情绪与语气 | 单一语调 | 按语义匹配表情与语调（严肃 / 积极 / 歉疚） |

## 六、商业化 / 产业化落地路径

1. **短期（本次参赛即可验证）**：小微企业知识前台——数字人形态直接复用现有"企业知识库 + AI 客服"产品线，
   参赛产出可作为一个交付形态给到已有客群（小微部署 + 年服务费模式）；
2. **中期**：把前台做成**行业模板**（零售服务 / 医疗器械 / 政务咨询 / 合规自查），
   一份行业语料包即可切换（本作品语料已是数据驱动、可整体替换）；
3. **长期**：与命题方生态互补——**它提供形象与驱动底座，我们提供企业知识、合规与交付能力**，
   共同面向小微企业的"知识库 + 数字人前台"打包交付，可对接私有化部署；
4. **社会价值（评审明确加分项）**：适老化与普惠——不会打字、看不清小字的群体同样能无障碍获得企业服务；
   **合规价值**：把国标 61 项自查做成人人会用的体检器，帮助小微企业在 AI 客服合规上少踩坑。
